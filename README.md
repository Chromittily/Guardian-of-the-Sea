# **_Guardian of the Sea_**

This is a single level Game Jam entry about Sustainability with a Mermaid theme. 

![image](https://github.com/user-attachments/assets/d3b2b8ba-71c0-4947-b792-eacc40c891b8)

## Where to Play:
https://chromittily.itch.io/guardian-of-the-sea  

**Note:** - This is best played in FULL SCREEN on the website. There is text cut-off present at the end of the game. I am addressing this in a new version of the game.

### Instructions: 
- Use WASD or normal keyboard controls to pick up litter in the sea! 

- Don't forget to save any animals along the way!

- There are ***8 TOTAL*** pieces of litter exposed to the marine life on this level!

- Find them all to win~!
